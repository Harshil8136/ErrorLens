# Code of conduct

## The short version

Be decent. Assume the other person is trying to help.

## What that means here

Technical disagreement is welcome and is most of what this repository is for.
Disagree with the code, the approach, the benchmark, the wording. Bring
evidence where you can.

Not welcome: personal attacks, harassment, demeaning comments about someone's
experience level, or the kind of dismissiveness that makes people stop asking
questions. Nobody is born knowing what a cgroup is.

If you're reporting a bug, remember there's a person on the other end doing
this in their spare time. If you're maintaining, remember the reporter took
time to write it up.

## Scope

This applies to issues, pull requests, discussions and any other project space.

## Enforcement

Report problems by opening a private security advisory (it's the only private
channel this repo has) or by emailing the maintainer listed in the commit
history.

I'll read it, and I'll act — a warning, deleting a comment, or blocking, in
proportion to what happened. I'll keep reports confidential.
